    THE SMALL EXAMPLE UNDER THE UI

    The host starts. The agent works. The host observes.

    The live path uses the root SDK on Node.js. The guided demo replays selected message fields so you can learn without a model account.

    TypeScript · the first query
    01

    The host supplies context

    prompt describes the task. options.cwd chooses the project. Configuration belongs inside options.

    02

    The agent can take steps

    A query can inspect files, request tools, and continue. In this sample, only Read, Glob, and Grep are available in live mode.

    03

    The stream is more than an answer

    Initialization, assistant activity, and tool results can arrive before a result. Check its subtype and error flag.

    04

    The host owns cleanup

    finally closes the handle on success, failure, or cancellation. See src/examples/first-query.ts for the runnable example.

    Two different kinds of streaming

    The SDK yields messages to the Node.js host. This sample then uses HTTP server-sent events to display a teaching view in the browser. That HTTP connection is our application’s transport.
